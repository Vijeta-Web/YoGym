## 📌 Project Overview
YoGym is a web-based gym registration interface designed to collect and validate user data efficiently. The system captures user details through a form and stores them in Google Sheets using API integration.

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Google Sheets API

## ⚙ Key Features
- User-friendly registration form
- Input validation using JavaScript
- Automatic data storage in Google Sheets
- Cloud-based data collection

## 🎯 Project Objective
The goal of this project was to build a simple web-based data collection interface that replaces manual form entry with automated and structured cloud storage.
